## Como estudar cada aula

1. Leia os objetivos e tente responder às perguntas de revisão sem consultar as
   notas.
2. Estude o resumo e reconstrua os exemplos em um projeto pequeno.
3. Consulte o PDF original para recuperar diagramas e o contexto da exposição.
4. Volte às perguntas e explique cada resposta com suas próprias palavras.

## Ideia que conecta a disciplina

Arquitetura de software é o conjunto de decisões estruturais usado para atender
requisitos de qualidade dentro de restrições reais. Não existe solução perfeita:
custo, prazo, conhecimento da equipe e risco sempre produzem *trade-offs*.

```text
requisito de qualidade + restrições + trade-offs → decisão arquitetural
```

As referências rápidas de [Docker](referencias/docker.md),
[AWS](referencias/aws.md) e o [glossário](referencias/glossario.md) servem como
apoio durante os exercícios.
